## 一、 先说最重要的一件事：公开的东西赚不到超额

```
 参考项目自己的诚实记录（它的 README 里写着）:
 · 早期报「夏普 1.86 / IR 1.21」 → 含 label 泄漏 → 修复后 OOS IR −0.13 ~ +0.2
 · V8（主力资金流 12 因子）→ 2025-2026 牛市 IR −0.75
 · 真实数据三轮收敛:
 ① LightGBM 揉 36 个因子 → OOS IC≈0 · t=−0.24 不显著
 ② 反转因子日频 IC「显著」（t=2.39）→ 重叠样本假象
 ③ 非重叠周频 + 扣冲击成本 → t 塌到 0.97
 → Top30 扣费后跑输等权 55%/年
 · 它的结论: 「2024-2026 A股牛市里没有可落地的公开因子 alpha」
 「继续堆公开因子 → 已被 4000+ 量化机构挖干净」
```

### → 与我们自己的实测互相印证

```
我们:
 6 个公开技术指标策略 × 19 只主板干净票 · 2018-2026 · 含真实费率
 → 平均超额全部为负（grid_classic −7.7% · boll_revert −37.9%
 · bias_revert −67.0% · macd_1d −72.1% · ma20_hold −78.2% · turtle −92.0%）

 两条独立的路径 → 同一个结论
 → 「公开的、简单的东西，在 A 股赚不到超额」
 → → 这不是我们的技术问题 是市场结构决定的
```

## 二、 一个我们必须马上记住的判据（我们的缺口）

```
 重叠样本 t 值虚高
 日频算「未来 5 日收益」→ 相邻样本重叠 4/5
 → IC 序列强自相关 → 而 t = mean/std × √n 把重叠当独立
 → → t 系统性虚高 （参考项目实测: 日频 t=2.39 → 非重叠后 t=0.97）

 正确做法:
 · 用非重叠样本（周频 / 月频）
 · 或 Newey-West 修正
 · 或 block bootstrap

 对我们的影响:
 · 今天那 114 个回测用总收益比较 → 不受重叠影响
 · 但以后任何 IC / 因子显著性检验→ 必须处理
 · → 写进判据清单，避免重犯
```

## 四、 一个完整的量化系统有哪几层（对照我们）

```
① 数据层 我们: QMT/xtdata 但复权不可复现 + 无因子库
 行情（tick/分钟/日线）· 财务 · 因子 · 另类（逐笔/Level2/新闻）

② 研究层 我们: 4 个基本面因子横截面选股 △
 因子挖掘 · 机器学习 · IC 检验 · 衰减监控
 参考项目的做法: Alpha158-lite + 反转/低波 + 涨停连板（16 因子）
 + 龙虎榜席位网络（13 因子）+ 资金流（12 因子）+ 日内（19 因子）+ regime（5 因子）
 → A股独有的因子才是差异所在（涨停连板 / 龙虎榜 / 席位网络）

③ 标签工程 我们完全没有
 多 horizon · 波动率归一化 · 横截面排序 · 停牌/一字板屏蔽

④ 中性化 我们完全没有
 Barra CNE5 六风格 + 行业中性（分层正交 + ridge）

⑤ 组合优化 我们完全没有（只有"等权买 N 只"）
 风险平价 · MVO · Black-Litterman

⑥ 执行层 △ 我们只有"限价挂单"
 TWAP / VWAP / POV · 冲击成本建模（固定 2bps → Almgren-Chriss + sqrt 律）

⑦ 成本模型 △ 我们有佣金 + 印花税 但没有滑点 / 冲击成本

⑧ 风控 我们做得不错
 涨跌停 · T+1 · 凯利 · 回撤熔断 · PreTradeGate · Regime 乘数

⑨ 记忆/自进化 我们完全没有
 交易反思入库 · 从成功交易聚类生成规则

⑩ UI / 可视化 用户已提需求
 参考项目: Streamlit 7 页 —— 今日信号仪表盘 · 个股详情（K线/因子画像）·
 Agent 辩论记录 · 回测与策略曲线（净值/回撤/IC 衰减/Barra 分解）·
 我的持仓 · 研究报告 · 明日操作台

⑪ 运维 △ 我们有看板 + 日志
 定时任务· 微信推送 · leak 自检
```

## 五、 我们的路线（基于上面的对照，按优先级）

### 阶段 A（现在 → 1 个月）: 让结论可信

```
A1 数据层重建（已在做）
 · 存不复权价 + 复权因子→ 可复现
 · 停牌日标 suspended 不存 0
 · 完整性审计能失败
A2 回测层复用 + 补上判据
 · 复用 13 个策略函数 与 ReplayMarket （已核实是纯函数）
 · 加滑点 / 冲击成本
 · 加重叠样本修正（IC/t 检验必须）
 · 加样本外切分（2018-2022 挑 → 2023-2026 验证）
A3 UI: 先做回测净值曲线叠加基准
 → 它直接服务于结论可信（一眼看出有没有跑赢）
 参考: Streamlit 7 页的实现 或者用现有的 Web（FastAPI + 前端）
```

### 阶段 B（1-2 个月）: 找差异化的方向

```
B1 A股独有因子 ← 这是唯一可能有效的方向
 · 涨停/连板/炸板/一字板（16 个因子）
 · 龙虎榜席位网络（游资联动 / 机构主导 / 接力）
 · 资金流（主力/超大单）
 · 而这些需要额外数据源 → akshare / 东财 （免费）
B2 标签工程 + 停牌/一字板屏蔽
 → 参考项目实测: 不屏蔽会让回测 IC 虚高 20-30%
B3 中性化（Barra CNE5）
```

### 阶段 C（3 个月）: 结论固化

```
C1 严格样本外验证（非重叠样本 + Newey-West）
C2 模拟盘长跑（真实规则下）
C3 如实报告结论 —— 无论答案是"有"还是"没有"
```

## 六、 一条重要的预期管理（参考项目的话）

```
「公开因子 + LightGBM + 月频选股，真实 OOS 夏普天花板 0.5-1.0」
「想突破需要: 付费数据（¥5-20万/年）· Level2 tick · 自监督模型 · 等 regime 切换」
→ → 所以我们的合理目标不是"找到高夏普策略"
 → 而是: 在个人可及的数据与工具下，把结论做到可信
 → 以及: 诚实回答"这条路对我们是否走得通"
 参考项目自己的定位就是: 「研究框架 + 实盘辅助工具，不是已验证的盈利策略」
 → 这个诚实本身，就是它最有价值的部分
```
