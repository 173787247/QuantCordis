# ep 因子通过市值中性化检验

> 上一轮的悬念: ep 超额 +235 个点，但未做中性化 → 可能只是小市值因子的代理
> 本轮: 做市值中性化 → 那是决定性检验
> 判据: 若组内超额消失 → 原超额只是小市值代理 · 若还在 → ep 有独立信息

---

## 一、 怎么做的

```
 ① 股本从哪来（库里没有市值字段）:
 · try 过价格代理 → 不行 —— 因为 ep = eps/price → 控制 price 就等于控制因子本身
 · try 过成交额 → 库里 amount 早年为
 · 用 xtdata 的 get_instrument_detail → 5,225 / 5,227 只 · 0.8 秒
 → 单位是股（600519 总股本 1.25008e9 = 12.50 亿股 与真实 12.56 亿接近）
 ② 市值 = 总股本 × 当时收盘价
 ③ 每个报告期按市值分 5 组 → 每组内按 E/P 排 → 取各组前 20%
 → 组合 = 5 组 × 各组 20%≈ 全市场 20% （实测每期 682-788 只）
 → 这样每组内都选 E/P 高的→ 市值分布与全市场一致
```

## 二、 结果: 超额几乎没变

| | Top20% | 全市场等权 | 超额 | 期数 |
|---|---|---|---|---|
| 不中性化 | +383.99% | +148.96% | +235.03% | 19 |
| 市值中性化 | +377.97% | +148.96% | +229.01% | 19 |

```
 只掉 6 个点（2.6%）→ 几乎没变
 → 所以 ep 的超额不是小市值代理
 → 它有独立的信息
 逐期: 13 / 19 期为正 → 与不中性化完全一致
```

## 三、这个结论现在有多硬（诚实评估）

```
 已验过的:
 · IC +0.0861 · t = +2.13（全市场 4,770 只/期 · 不重叠 → t 可信）
 · 分层超额 +235.03%（19 期 · 13 期正 · 最大单期 +27.43% → 不集中）
 · 市值中性化后 +229.01% → 保留 97.4%
 · 防未来函数: 法定披露截止日
 · eps 已按报告期年化（修过一个错）
 · 成本 0.16%/次已扣
 · 流动性: 有数据那期 Top 中位成交额 1.98 亿
 还没验的:
 · 样本外 —— 19 期全用了 → 必须分两段 ← 下一步
 · 涨停 / 停牌过滤（那些买不进 → 会高估收益）
 · 行业中性化（只做了市值）
 · 股本用的是当前值 → 历史市值有偏差
 → 但中性化只需粗分组 → 可接受 （已注明）
 · amount 旧期为空 → 只验证了一期的流动性
 · 换手/冲击成本（现在只有固定 0.16%）
```
