# 基本面家族检验 —— 也不是新家族

> 动机: 六个技术策略平均相关 0.528 → 它们是同一个信号 → 组合无用
> → 所以要找真正独立的信号 → 换数据来源 → 选基本面（库里已有财报）
> 判据: ① rho 与技术策略低（< 0.3）→ 新家族 ② 组合有分散化收益
> 样本: 19 只主板 · 2020-01-01 → 2026-06-30（财报只有 2020 起 → 必须同区间）
> 含滑点 0.05%

---

## 一、 未来函数怎么防（本策略最关键的部分）

```
 财报表只有 report_date（没有公告日）
 → 直接用就是偷看未来
 所以用法定披露截止日（A股规则确定的）:
 一季报 03-31 → 4 月 30 日· 半年报 06-30 → 8 月 31 日
 三季报 09-30 → 10 月 31 日· 年报 12-31 → 次年 4 月 30 日
→ 报告期 + 到截止日之后才可用 → 零未来函数
 → 代价: 比实际公告晚 1-4 个月 → 但方向保守
 已验证: 2026-06-30 → 2026-08-31 · 2025-12-31 → 2026-04-30
```

## 三、 三个关键发现

### ① 基本面的"超额"是统计假象

```
 roe 与 low_debt 的均交易 = 1 笔
 → 它们只买了一次从不卖 → 退化成"选几只长期持有"
 → 为什么超额好看而净值很差:
 · 超额 = 策略收益 − 同票买入持有
 · → 而选中的票基数不同 → 平均超额会被高基数的票拉高
 · 而组合净值才是真相: roe +21.27% · low_debt +1.60%
 → → 对比买入持有 +51.27% → 跑输 30-50 个点
```

### ② rho 判据: 都不是新家族

```
 roe vs 六个技术策略: 平均 |rho| = 0.521
 low_debt vs 六个技术策略: 平均 |rho| = 0.661
 → 判据是 < 0.3 → 两条都不通过
 为什么基本面会与技术指标相关:
 · ROE / 负债率常年稳定 → 它们决定了票的长期走势类型
 · → 而技术策略在同一只票上做多做空→ 自然相关
 · → 即: 它们不是独立的信号 → 而是同一批票的不同时间切法
```

### ③ 组合只多 0.14 个点

```
 纯技术（6 个） +28.97%
 加基本面（8 个） +29.11%→ 多 0.14 点
 → 分散化无收益
```

## 四、 顺带发现 grid_classic 不稳

```
 2018-2026: 超额 +4.65% · 2020-2026: −13.98%
 → 换区间结论就变了 → 与第 13 轮的结论一致（滑点吃掉）
```

## 五、结论

```
 基本面也不是新家族（rho 0.521 / 0.661）
 → 而更根本的是: 在同一批票上做不同的切法→ 必然相关
 → → 即: 问题的不是用什么数据
 → 而是这 19 只票 + 这个框架本身只有一个信息来源
 → 即: 价格（而基本面也是同一批票的属性）
```

## 六、下一步该换什么而不是换数据

```
 前面四次（技术指标 · A股独有 · 情绪择时 · 组合）
 + 本次（基本面）→ 都是在同一批票上找信号
 → 真正不同的方向应当是:
 · 扩大票池（19 只 → 全市场）→ 横截面才有统计意义
 → 因为19 只里排名前 3和排名后 3的差别没有统计力
 · 或者换标的类别（可转债 · ETF 轮动）
 · 或者换频率（分钟级 → 但策略库不支持）
 → 而最可能有价值的是第一条: 扩大票池
 → 因为横截面因子需要足够的宽度
 → → 19 只做横截面选股本身就是错的方法
```
