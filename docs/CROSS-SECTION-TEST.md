# 全市场横截面因子检验 —— 第一个正面结果

> 动机: 19 只做横截面选股本身就是错的方法（排名前 3 与后 3 没有统计力）
> → 扩大到全市场 → 用库（有全市场 10,677,641 行 不用逐只拉）
> 样本: 5,294 只· 26 期· 每期约 4,770 只
> 防未来函数: 法定披露截止日（一季报 4/30 · 半年报 8/31 · 三季报 10/31 · 年报次年 4/30）
> 不重叠: 用季度末因子预测下一季度收益 → t 值可信（重叠会虚高）

---

## 一、 IC 检验（Spearman 秩相关 不重叠）

| 因子 | 期数 | IC 均值 | IC 标准差 | IC>0 比例 | t 值 |
|---|---|---|---|---|---|
| roe | 12 | +0.0687 | 0.1361 | 75.0% | +1.75 |
| low_debt | 12 | +0.0647 | 0.0879 | 83.3% | +2.55 |
| ep | 12 | +0.0861 | 0.1402 | 83.3% | +2.13 |

```
 判据: |t| > 2 → 有预测力 · IC > 0.02 → 经济上有意义
→ 四个里三个通过 → IC 均值全在 0.065-0.086 → 远高于门槛
```

## 二、 分层回测（这才是关键）

Top20% 组合（扣成本 0.16%/次）vs 全市场等权:

| 因子 | Top20% | 全市场等权 | 超额 | 期数 |
|---|---|---|---|---|
| ep | +383.99% | +148.96% | +235.03% | 19 |
| growth | +95.09% | +92.43% | +2.66% | 16 |
| roe | +125.17% | +148.96% | −23.79% | 19 |

```
 ep 超额 +235 个点 → 第一个正面结果
 而 growth 只有 +2.66%（修正后从 +55.32% 掉下来）
 roe / low_debt 跑输（而它们的 IC 是正的）
 → → 所以 IC 正不代表组合能赚钱（因子研究的关键结论）
```

## 四、 ep 的稳健性（逐期拆解）

```
 19 期里 13 期为正（负的 6 期: −3.57 · −3.25 · −1.90 · −12.77 · −5.18 · −4.76）
 → 不是一两期主导（最大单期 +27.43%）
 流动性: Top20% 的中位成交额 = 1.98 亿元 → 可交易
 → 但只有 2026-03-31 那期有值 → 库里 amount 在早年是空的
```

## 五、 边界（必须写清 —— 这不等于"能赚钱"）

```
 ① 未做市值 / 行业中性化
 → ep = eps/price → 低价股 E/P 天然高
 → 而低价股往往是小市值 → 所以这个超额可能只是小市值因子的代理
 → → 而小市值在 A股长期跑赢是已知现象 → 但那不是 alpha
 → 是风险溢价或壳价值
 ② 未做样本外（19 期全用了）
 ③ 未考虑涨停买不进 / 停牌
 ④ amount 旧期为空 → 只验证了一期的流动性
 ⑤ 成本假设 0.16%/次是单边买卖合计 → 而实盘还有冲击成本
```

## 六、下一步（按重要性）

```

 → 判据: 若组内超额消失 → 原超额只是小市值代理

 ② 样本外: 2020-2023 定规则 → 2024-2026 验
 ③ 补 amount → 验全周期流动性
 ④ 涨停/停牌过滤
```

