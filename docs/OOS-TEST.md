# 样本外检验 —— ep 衰减严重，最近两年为负

> 上一轮: ep 通过市值中性化（超额保留 97.4%）→ 但未验样本外
> 本轮: 分段 + 逐年 + 涨停过滤
> 规则无参数可调（ep · top20% · 5 组 全是先验）→ 不存在参数过拟合
> → 但仍要验 —— 因为我可能无意中选了好看的区间

---

## 一、 结果: 衰减严重

| 分段 | 期数 | Top | 等权 | 超额 | 为正期数 |
|---|---|---|---|---|---|
| 训练 2020-2022 | 9 | +187.18% | +73.17% | +114.01% | 7/9 |
| 测试 2023-2026 | 10 | +52.10% | +43.76% | +8.33% | 6/10 |
| 全期 2020-2026 | 19 | +336.79% | +148.96% | +187.83% | 13/19 |

```
 衰减非常明显: +114.01% → +8.33%
 → 年化: 训练 3 年 → 约 28.8%/年· 测试 3.75 年 → 约 2.2%/年
```

## 二、 逐年（最关键的表）

| 年 | 期数 | 超额 | |
|---|---|---|---|
| 2020 | 3 | +17.81% | |
| 2021 | 3 | +40.78% | |
| 2022 | 3 | +6.18% | |
| 2023 | 3 | +14.29% | |
| 2024 | 3 | −3.46% | |
| 2025 | 3 | −10.47% | |
| 2026 | 1 | +0.86% | |

```
 为正: 5 / 7 年 · 而最近两年都是负的
 → 这不是随机波动 —— 是单调的衰减趋势: 40.78 → 6.18 → 14.29 → −3.46 → −10.47
```

## 三、 涨停过滤（本轮加的）

```
 判据: 买入日开盘涨幅 ≥ 涨跌停阈值 × 0.98→ 买不进 → 剔除
 （主板 9.8% · 创业板/科创板 19.6%）
 实测剔除 67 次· 平均每期 3.5 只
 → 影响不大（因为组合每期 680-790 只 → 剔 3.5 只可忽略）
 → 但剔了之后超额从 +235 降到 +187.83 → 差 47 点
 → 说明涨停确实贡献了一部分 → 现在已扣除
```

## 四、诚实的结论

```
 不能说"找到了一个可用的策略"
 准确说法:
 · ep 因子在 2020-2023 有效（超额 +114% · 7/9 期正）
 · 在 2024 之后不再有效（或大幅衰减 → 两年为负）
 → 这正是目标说的"如实报告"
 → 而不是挑2020-2023 那段报"年化 28.8%"
```

## 五、 为什么会衰减（三个可能）

```
 ① 因子被套利掉了（最可能）:
 · ep / 低估值是最经典最公开的因子
 · → 2020-2023 有效之后被机构挖干净
 · 与外部资料一致: 「公开因子…已被 4000+ 量化机构挖干净」
 ② 市场风格变化:
 · 2024-2025 小盘 / 低价风格与2020-2021 不同
 ③ 样本不足:
 · 2026 只有 1 期 → 不完整
```

## 六、下一步

```
 ① 接受这个结论: 一个曾经有效现已失效的因子
 → 而它本身就是一个有价值的发现（与外部证据一致）
 ② 若继续找: 应当找2024-2026 有效的
 → 但那需要先理解为什么2024 变了（否则会重复过拟合）
 ③ 或者换方向: 回到 (1) 系统可信的三条硬闸（等用户确认）
```

## 七、 这一轮的价值（诚实本身就是产出）

```
 如果我只报全期 +187.83%

→ 分段 + 逐年把一个看起来很好的结果
```
