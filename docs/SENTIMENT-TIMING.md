# 市场情绪择时 —— 信号存在，但口径要换

> 动机: 6 个公开技术指标策略 + 首板策略在含成本下全部跑不过买入持有
> → 从选股换到择时 —— 用市场情绪决定做多还是空仓
> 为什么可能有效: 外部资料的原话「多头选股策略在 FOMO 牛市天生劣势」
> → 而择时正好治这个

## 一、指标（只用日K 横截面统计 一个 SQL 扫全历史）

```
 涨停家数 = count(涨幅 ≥ 9.8%)
 触板家数 = count(盘中最高 ≥ 涨停价)
 涨停占比 = 涨停家数 / 全市场 ← 剔除市场扩容影响
 封板率 = 涨停家数 / 触板家数
 全市场等权收益（用于检验）
 涨停阈值为什么用 9.8% : 涨停价按前收四舍五入到分→ 有时 9.98% 有时 10.02%
```

## 二、 涨停占比有预测力，封板率没有

| 档位 | 涨停占比区间 | 次日全市场等权收益 | 胜率 |
|---|---|---|---|
| 第1档 | 0.3%~0.9% | −0.0086% | 53.8% |
| 第2档 | 0.9%~1.3% | −0.0011% | 53.4% |
| 第3档 | 1.3%~1.7% | +0.1344% | 57.2% |
| 第4档 | 1.7%~2.3% | +0.0652% | 53.6% |
| 第5档 | 2.3%~55.4% | +0.2488% | 58.6% |

```
 前两档为负、后三档为正 → 有单调性
 封板率: 第5档 − 第1档 = −0.0555% → 无单调性（甚至反向）→ 放弃
```

## 五、 但口径有问题（发现并记下）

```
 这不是策略收益 —— 它是全市场等权收益
 → 意味着每天买 5,000 只股票 → 不可能实现
 → +0.2328%/天 × 242 = 年化 56% → 在 A股不可能持续
 → → 所以这个数是信号存在的证据 不是可交易策略的收益
 真实可交易的是指数或 ETF（沪深300 / 中证500 / 中证1000）
 → 而指数 ≠ 全市场等权 → 必须换成可交易标的验证
```

```

### 分化非常合理（这解释了机制）

```
 涨停是散户/游资行为 → 集中在中小盘
 大盘股涨停少 → 情绪指标对它们无预测力
→ → 信号来源: 中小盘的情绪溢出
 → 而它不是"全市场等权"的假象 —— 是中小盘这个真实板块的性质

## 十六、 ST 缺口的量级

### 两条路，一条断一条通

```
 download_his_st_data → 「当前客户端未支持此功能，请更新客户端或升级投研版」
 → ST 的历史数据拿不到 → 这是明确的、不可绕过的限制
 get_instrument_detail → 能拿股票名称 → 名称里带 ST 就能判
 → 而且极快: 抽样 200 只 0.0 秒→ 全部 5,227 只约 1 秒
 → 抽样里 ST 有 4 只 → 估计全市场约 104 只（占 5,227 的 2.0%）
```

### → 缺口的量级: < 2%

```
 用当前名称判 ST → 只能拿到今天的名单
 → 历史某天它是不是 ST不知道（没有历史 ST 数据）
→ 但上界可以算:
 ST 只有 104 只 → 即使全部涨停→ 也占 104/5,227 = 2%
 → 所以 ST 缺口 < 2%
→ 而且情绪分档是相对排序 → 2% 的偏差几乎不影响排序
 → 结论: 缺口不致命 → 前面的结论不受影响
```

### 写清楚（诚实边界）

```
 能做的: 用名称判当前ST → 104 只 → 可以在计算时排除或单独处理
 不能做的: 还原历史上每一天的 ST 状态
 → 所以严格的历史情绪指标仍有 2% 以内的偏差
 但它不影响: 分档是相对的 · 2% 的噪声不改变排序
```
