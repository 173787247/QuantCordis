# 策略筛选：在可回测的全样本上跑六个策略

> 样本: `quantcordis_bar_none` 里全部 1056 只（不筛选，不挑好看的）
> 区间: 2018-01-01 → 2026-06-30
> 费率: 佣金万二点五（双边）+ 卖出印花税千分之零点五（ETF 免印花税）
> 成交: 信号在 K_i 收盘出，用 K_{i+1} 开盘成交
> 判据: 均值超额 > 0 且 中位超额 > 0 且 为正只数 > 50%（三条同时成立才算有超额）
> 超额 = 策略收益 − 同期买入持有（两者同口径，后复权）

## 一、为什么是三条判据

均值会被少数极端值主导。此前实测里就有这样的例子：某策略均值负十一，中位却是正九点一七，
十九只里十一只为正 —— 只报均值会把分布的形状说反。加上中位与为正比例之后，这一类策略会
在「均值」那一栏被挡住，而它的真实形状仍然看得见。

## 三、滑点检验：唯一过关的那个，不扛滑点

判决的下一步是给那个唯一过关的策略加滑点。判据不变，三条同时成立。

| 单边滑点 | 均值超额 | 中位超额 | 为正只数 | 均交易数 |
|---|---|---|---|---|
| 0（回测默认） | +3.94% | +33.51% | 703/1052 | 27.3 |
| 0.1% | **−1.31%** | +29.10% | 691/1053 | 27.3 |
| 0.2% | **−6.26%** | +26.49% | 686/1053 | 27.3 |

```
单边 0.1% 时均值超额就翻负了，判据不再三条都过。

而中位超额一直是正的（+33 → +29 → +26），为正比例也一直过半
（703 → 691 → 686）。所以它不是「没有信号」——它的信号是真的，
只是这笔信号赚到的钱正好与交易成本同量级，而它平均每只要交易
二十七次。

单边 0.1% 对 A 股是保守的假设（常见区间 0.05% 到 0.15%）。
它连保守假设都扛不住。
```

**结论：在能做的样本上，找不到既三条都过、又扛得住保守滑点的策略。**
如实报告，不挑好看的数。

## 四、读上面两张表要注意的三件事

```
① 只有 grid_classic 三条都过，而它的均值只有 +3.94%。
   这个余量比「未建模的滑点」还小：它平均每只交易 27.3 次，
   而回测默认滑点为 0。按每次往返 0.1% 单边估，成本量级约 5%，
   足以把这个 +3.94% 抹平。⇒ 它过的是「有没有信号」这一关，
   不是「能不能交易」这一关。滑点检验见下一节。

② boll_revert 的形状值得单独看：中位 +33.00%、693/1053 为正，
   而均值 −11.30%。它不是没有信号，是分布的左尾很长。
   这一类策略用「均值」一个数会误判成没有价值。

③ 六个策略里四个连中位都是负的。均值超额为正的只有一个。
   按目标的要求，这一轮如实报告：在能做的样本上，找不到
   「稳、且余量足够大」的超额。
```

## 七、复现：换一个与上面完全不重叠的样本

上面那次用的是 1056 只（干净池每五取一）。之后新表铺到 5185 只，条件齐了，
于是换一个**与上面零交集**的样本重跑同一批策略，看结论站不站得住。

```
样本: 从 5185 只里每四取一，再显式剔除上面那 1056 只 ⇒ 1036 只
      （剔除后 4129 + 1056 = 5185，数字自洽，即交集为零）
区间与费率与上面完全相同
```

| 策略 | 旧样本(1056) 均值 / 为正 | 新样本(1036) 均值 / 为正 | 判定 |
|---|---|---|---|
| grid_classic | +3.94% / 703/1052 | **+17.66% / 714/1032** | 两个样本都过三条 |
| boll_revert | −11.30% / 693/1053 | **+5.75% / 685/1032** | ★ 翻转（一个不过、一个过） |
| bias_revert | −35.03% / 623/1053 | −15.29% / 633/1032 | 都不过 |
| macd_1d | −36.96% / 512/1053 | −27.19% / 513/1032 | 都不过 |
| ma20_hold | −52.26% / 454/1053 | −40.63% / 434/1032 | 都不过 |
| turtle_donchian | −79.08% / 333/1053 | −63.84% / 337/1032 | 都不过 |

### 读这张表的三件事

```
① grid_classic 在两个零交集的样本上都过三条，而且中位数同量级
   （+33.51% 与 +39.23%）。所以它的**信号**是真的，这一点被复现了。

② 但把滑点加上去，结论就不一样了：

     样本        0% 滑点    0.1% 滑点
     旧 1056     +3.94%     −1.31%   ← 不过
     新 1036    +17.66%    +12.57%   ← 仍然过

   同一个策略、同一个区间、同一个费率，只换样本，滑点之后的判定就翻了。
   所以「它扛不扛得住滑点」这句话，**在现有证据下不能下**。
   能下的只有：它的毛信号稳，净收益是否为正**取决于样本**。

③ boll_revert 是另一种情况：中位数一直很高（+33% / +28%），
   两个样本上为正都过半，而均值一个 −11.30% 一个 +5.75%。
   它的均值被左尾主导到会在零点附近翻来覆去，所以它的判定是**判不了**，
   既不能说它是好的，也不能说它是坏的。
```

### 结论

**在能做的样本上，找不到一个「净收益稳健为正」的策略。**
grid_classic 的毛信号可复现，但净收益的符号随样本变；
boll_revert 的均值随样本在零点两侧跳。这两条都如实记下来，不挑好看的那一半。
