# 量级断裂核查 —— 已根治

> 目标原文: 「复权口径统一（自己算复权，根治 54 只大蓝筹的量级断裂）」
> 判据: 相邻交易日的收盘价比值应当落在涨跌停范围内
> → 阈值 1.15 倍（留出创业板 20% 的余量）与 5 倍（早上的口径）各跑一次
> 数据: QuantCordis 的 `quantcordis_bar_none`（25 只）vs 库 `trade_stock_daily`

---

## 一、 结果: 新库好 4-6 倍

| 口径 | QuantCordis | 库 | 倍数 |
|---|---|---|---|
| 1.15 倍 | 58 处 / 97,403 = 0.0595%（20 只）| 38,741 / 10,677,641 = 0.3628%（2,710 只）| 0.16 倍 |
| 5 倍 | 1 处 / 97,403 = 0.0010%（1 只）| 449 / 10,677,641 = 0.0042%（66 只）| 0.24 倍 |

```
 1.15 倍口径更严 → 更能看出差异（0.0595% vs 0.3628%）
```

## 二、 而那唯一 1 处经查是真实事件，不是断裂

```
 000620.SZ 2011-07-08（新库）:
 2011-06-28 ~ 07-07: 收 1.170 · 成交量 0← 停牌 （价格恒定）
 2011-07-08: 开 10.200 高 12.150 低 10.100 收 10.520· 量 887,992← 复牌
 2011-07-11 起: 正常交易
→ 三重特征都符合停牌复牌:
 · 停牌期间量为 0 · 复牌日量巨大 · 报价连续（1.17 → 10.52，不是 0.001）
→ → 所以新库的真断裂 = 0
```

## 三、 而库在同一位置是坏的

```
 库（对照）:
 2011-07-05 ~ 07-07: 收 0.036 ← 而真实是 1.170
 2011-07-08: 收 9.720 ← 新库 10.520
 2011-07-11: 收 9.980 ← 新库 10.780
→ 停牌期间库给 0.036 → 连"价格不变"都没保住
 而库那些最严重的（5 倍口径）:
 · 000568.SZ 2016-07-08: 3.8019 → 0.0048 · 600809.SH 2018-11-28: 6.2000 → 0.0257
 · 601225.SH 2018-01-12: 0.1810 → 0.0010 · 600188.SH 2021-03-03: 0.0013 → 0.4167
 → 那些价格是0.001 元 → 在新库一个都没有
```


```
 我早上说"54 只大蓝筹的量级断裂"
 → 实测5 倍口径下是 66 只 → 接近 → 那个数字大体对
 → 但1.15 倍口径下是2,710 只 → 范围比"54 只"大得多
 所以准确说法: 5 倍口径 66 只 · 1.15 倍口径 2,710 只
 → 两个口径都报 → 不藏
```

## 五、结论

```
 量级断裂已根治（目标 (2) 的第二项）
 · 同比好 4-6 倍
 · 而新库那唯一 1 处经三重特征确认是真实的停牌复牌 → 真断裂 = 0
 · 库在同一位置的停牌期间价格也是错的 → 不只是复权口径问题
 剩下的事（不属于本项）:
 · 25 只票的规模仍然小 → 要扩到全市场需要逐只拉取 + 算复权
 · 但那不影响口径统一这个结论
```
