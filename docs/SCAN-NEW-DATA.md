## 二、 最重要的发现: 均值会骗人

```
 boll_revert: 均值 −11.03%· 中位 +9.17% · 11/19 只为正
 macd_1d: 均值 −29.87%· 中位 +4.31% · 10/19 只为正
 grid_classic: 均值 +4.65% · 中位 +12.35% （中位更好）
→ → 均值被少数极端亏损主导 → 分布严重偏斜
 → 只报均值会误导 —— 它会让人以为"三个策略都是负的"
 而中位数说有两个是正的
→ 写法要改: 均值与中位都报 · 并且报为正只数（分布的形状）
```

## 四、诚实的结论

```

 且 +4.65% 不足以覆盖滑点

```

## 七、 滑点敏感性

> 滑点两种建模都做（真实市场里两者都有）:
> · 比例: 买价 ×(1+s) · 卖价 ×(1−s)
> · 最小变动单位: A股 0.01 元 → 买 +0.01 · 卖 −0.01
> 买入持有基准也扣同口径滑点（各买卖一次 → 公平）

### grid_classic（无滑点时是唯一为正的）

| 滑点档 | 均值超额 | 中位超额 | 为正只数 |
|---|---|---|---|
| 无滑点 | +4.65% | +12.35% | 11/19 |
| 比例 0.05% | +1.98% | +9.44% | 10/19 |
| 比例 0.1% | −0.64% | +6.57% | 10/19 |
| 1 跳（0.01 元）| +1.87% | +9.53% | 11/19 |
| 比例 0.1% + 1 跳 | −3.33% | +3.85% | 10/19 |

### boll_revert（无滑点时均值 −11.03%）

```
无滑点 −11.03% · 0.05% −15.91% · 0.1% −20.63% · 1跳 −16.47% · 0.1%+1跳 −25.68%
→ 任何滑点档全部为负 → 直接排除
```

### 结论

```
 滑点只要到 0.1% → grid_classic 就转负（−0.64%）
 → 而真实 A股滑点通常 0.1-0.2%（小资金可能 0.05%）
→ → 含滑点后: 一个都没有
 → 这正是目标要求的如实报告「找不到」 · 不挑好看的数
```

### 机制解释（不是偶然）

```
 grid_classic 均交易仅 31 笔（换手不高）
 → 但它是网格策略 → 每笔盈利空间只有几个格子
 → → 滑点占每笔利润比例很大
 对比 ma20_hold（趋势策略）→ 每笔利润空间大 → 滑点占比小
→ → 这是"小利润策略对成本最敏感"的实例
```

### 覆盖的判据链（每一条都能失败）

```
① 无滑点: 1/6 为正（grid_classic +4.65%）
② 加 0.05% 滑点: 仍 +1.98%
③ 加 0.1% 滑点: 转负 → 判据被推翻
④ 加"比例+1跳": −3.33% → 更硬地推翻
→ 判据在每一档都可能翻 → 而它确实翻了 → 这就是"能失败"
```
