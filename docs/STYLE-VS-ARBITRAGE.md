# 为什么 ep 失效了 —— 不是风格，是因子被套利

> 为什么要查: 上一轮发现 ep 在 2024-2025 为负
> → 但「失效」有两种可能，处理方式完全不同:
> · 风格切换→ 小盘/低价整体跑输 → 风格会回来 → 因子仍可能可用
> · 因子被套利→ 小盘仍赢但组内无效 → 不会再回来
> → 不区分这两者就会重复过拟合

---

## 一、 判别方法

```
 每期按市值分 5 组→ 看各组收益 → 那就是风格曲线
 两个假设的可证伪预测:
 · 假设① 风格切换 → 预测: 小市值在 2024-2025 跑输大市值
 · 假设② 被套利 → 预测: 小市值仍赢 但组内 ep 无效
```

## 二、 结果: 假设①被证伪，假设②被证实

| 时期 | 期数 | 小市值 − 大市值 | 为正 |
|---|---|---|---|
| 2020-2022 | 9 | +10.76% | 8/9 |
| 2023-2026 | 10 | +5.65% | 8/10 |
| 2024-2025 | 6 | +7.97% | 6/6 |
| 2023 | 3 | +3.94% | 2/3 |
| 2024 | 3 | +9.97% | 3/3 |
| 2025 | 3 | +5.97% | 3/3 |

```
 小盘在 2024-2025 仍然明显跑赢（6/6 期为正）
 → → 假设①被证伪（若是风格切换 → 小盘应当跑输）
 → → 假设②被证实: 因子本身失效
 → 小盘仍赢 → 但在小盘组内ep 不再有超额
 → → 即: 它真的被套利掉了
```

## 三、 这与外部证据一致

```
 外部资料的原话: 「公开因子…已被 4000+ 量化机构挖干净」
 本轮的证据:
 · 2020-2022: 小盘 +10.76% · ep 组内超额 +114% → 双重红利
 · 2024-2025: 小盘 +7.97%（红利仍在）· 而 ep 组内转负
 → → 所以消失的正是ep 那部分 → 不是小盘那部分
 → 即: 市场还在给小盘溢价 但不再给低估值溢价
```

## 四、怎么办（三条路）

```
 ① 接受并记录 —— 一个曾经有效、现已失效的因子的完整证据链
 → 它本身就有价值: 它说明"公开因子会被套利"是真的
 ② 找未被套利的因子:
 · 越来越难 —— 任何我在公开数据上能发现的 → 大概率也被套利过
 · 而且每多试一个因子 → 过拟合风险就多一分
 ③ 换赛道:
 · 不再找因子选股→ 做别的
 · · 系统可信（方向 (1) → 三条硬闸未实现 → 等用户确认）
 · 工程化: 把研究固化成可复用的管道 （而不是一次性脚本）
 · 执行质量: 交易成本 · 滑点 · 冲击→ 那是真实可改善的
 → 而现实地说: 方向 (1)和执行质量是能真改变结果的
 → 而"再找一个因子"大概率不会
```
