# A股独有现象的第一个测试：首板策略

> 动机: 6 个公开技术指标策略在含费率与滑点下平均超额全负
> → 换空间: 找 A股独有的现象 （涨跌停制度 → 美股不存在"连板"）
> 为什么先做涨停: 只用日K 就能算 → 不需要新数据源

---

## 一、策略口径（写清楚 → 可复核）

```
 涨停判定: 涨幅 ≥ 9.8%
 → 为什么不用 10% 整 : 涨停价按前收四舍五入到分
 → 有时 9.98% 有时 10.02% → 9.8% 是稳的界
 首板: 今日涨停 且 昨日未涨停
 排除一字板: 开 == 高 == 低 == 收 且涨停
 → 为什么排除 : 一字板买不进（真实约束 不是策略选择）
 买入: 信号在涨停日收盘出 → 次日开盘成交（回测器统一规则）
 卖出: 持有 3 天 或跌破买入价 5%
 参数只有两个 → 不容易过拟合
```

## 二、 结果: 0 / 4 为正

| 滑点档 | 均值超额 | 中位超额 | 为正只数 | 均交易 |
|---|---|---|---|---|
| 无滑点 | −80.26% | −81.67% | 4/19 | 43 |
| 比例 0.1% | −83.50% | −85.22% | 4/19 | 43 |
| 1 跳 | −82.65% | −83.06% | 4/19 | 43 |
| 0.1% + 1 跳 | −85.70% | −86.54% | 4/19 | 43 |

```
 比公开技术指标策略更差（boll_revert −11% · grid_classic −0.6%~−3.3%）
→ 如实报告
```


```
 ① 信号在涨停日收盘 → 次日开盘买
 → 涨停股次日往往高开 → 买入价高 → 亏
 → 这是打板策略的固有代价
 ② 2018-2026 是震荡/结构市 → 涨停次日回落是常态
 → "打板"在震荡市表现差是已知现象
```

## 四、 边界（必须说清，否则会过度解读）

```
 我测的是: "首板次日开盘买、持有 3 天或止损 5%"
 不是完整的龙头战法 —— 那个要:
 · 选龙头（当日涨停里最强的）
 · 看量能（放量 vs 缩量）
 · 看情绪周期（连板高度 · 炸板率）
 · 分批进出
→ → 所以准确的说法是:
 "首板后无脑持有 3 天"跑不过
 不能据此说"A股独有因子无效"
```

## 五、 下一轮该做什么

```
 ① 选龙头: 不只"首板"，而是当天所有涨停里封单最大/最早封板的那只
 → 数据需求: 封单量 / 首次封板时间 → 日K 没有
 → → 但可以用近似: 换手率低 + 涨停 + 市值大 → 更可能是龙头
 ② 连板高度: 统计全市场当日最高连板数 → 那是市场情绪指标
 → 而它只用日K 就能算（扫全市场 我们库里有）
 ③ 炸板率: 全市场盘中触及涨停但收盘未封的比例
 → 同样是市场情绪指标 只用日K
 → 所以下一步: 把"连板高度"与"炸板率"做成市场情绪因子
 → 用它来开关策略（情绪高时做多 · 情绪低时空仓）
 → 那不再是"选股策略" 而是择时 —— 换个方向
```
