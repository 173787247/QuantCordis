# QuantCordis 的端口与接口约定

## 端口

```
 QuantCordis: 7875（127.0.0.1 只绑本机）
 旧实例: 7865
→ 两者可以同时运行 —— 这是路线图阶段 3「并排对照」的前提
```


```
 借用参考实现的端口 → 两个问题:
 ① 不能同时跑 → 就没法并排对照行为
 → 而"新引擎的行为被验证过"是切到它的前提
 ② 改配置要重启服务
 → 会打断正在运行的实例
 → 分开端口 → 两边互不干扰
```

## 现在有什么（诚实）

```
 目前 QuantCordis 还没有 Web 服务层
 → 只有 data/ 下的命令行脚本
 → 所以"端口"这一条现在只是约定 等有了服务再用
 已有的命令:
 python data/db.py # 连接自检（能失败）
 python data/bar_none.py --code ... --audit --verify-twice
 python data/pool.py [--json] [--check CODE]
```

## 以后加服务层时的规矩（先写下）

```
① 只绑 127.0.0.1 （永不用 0.0.0.0）
② 端口从 QUANTCORDIS_PORT 读 （默认 7875 不硬编码）
③ 与参考实现不共用 —— 它们是两个独立进程
④ 起服务前先确认 7875 没被占（能失败）
```
