# 复权公式 —— 已确认的部分与未解决的线索

## 一、 已确认: `dr` 的语义

```
 实测（茅台 2026-06-26 那次除权 只有现金分红、无送转）:
 除权日之前: none − front = 28.0242（每一天精确相同）
 除权日及之后: front == none （归一）

 而分红表给: interest = 28.02423 · dr = 1.023663
 验算: 1212.10 / (1212.10 − 28.02423) = 1212.10 / 1184.0758 = 1.023671
 而 dr = 1.023663 → 吻合到 5 位
→ → dr = 前收 ÷ 除权参考价
 → 送转也解释得通: 2006 年 stockGift=1.0 → dr=2.006365 → 股本翻倍、价格腰斩

 用法: front(t) = none(t) × Π(1/dr for ed > t) （乘 1/dr 不是乘 dr）
 验算: 1212.10 × (1/1.023663) = 1184.08
```

## 二、 一个更有价值的发现: `front` 自己大量是坏的

```
 判据: front ≤ 0，或与前/后 5 日内任一合理值的比值 >2 或 <0.5 → 判为断点
 实测（茅台 2001-2026 · 6,093 天）:
 · xtdata 的 front: 3,631 天是断点 = 59.6%
 · 我重建的值: 10 天异常 = 0.16%
 直观例（2016-07）:
 日期 none 重建 xtdata的front
 20160704 293.90 238.08 2.2428
 20160705 300.58 243.49 8.9228
 20160706 317.19 256.95 25.5328
 → 我的重建是平滑连续的 而 front 在跳跃
 → 而且 none = 293.90 是合理价 front = 2.24 显然坏
→ → 所以"自己算复权"的价值不只是"可复现"
 → 而是比数据源给的更可信
 → 这正是重建数据层的核心理由
```

## 三、 未解决: 全历史重建还差一个因子

## 五、当前可用于生产的程度（诚实）

```
 可用于: 判断 front 哪些日子坏了（59.6% 断点 → 这个结论很硬）
 可用于: 重建一个连续的复权序列（自身只有 0.16% 异常）
 不可用于: 宣称与数据源一致（还差一个因子未定位）
→ 建议: 在差因子定位之前，回测用后复权（后复权是最新基准的镜像
 → 或者用 none 直接回测（不依赖复权 只影响跨除权的收益计算）
```
