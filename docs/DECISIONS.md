# QuantCordis 的设计决策

## D2 · · 数据层自己算复权

决定: 从 xtdata 拉不复权价 + 复权因子，复权在本地算。

理由:
- 库的价格是前复权 → 每次分红都会重算历史 → 同一段回测在不同时间跑，结果不同
- 前复权在极端分红下会算出负数（实测 48,217 行）
- 自己算 → 因子突变 = 断裂 → 可查、可复现、可追溯到抓取时间

代价: 一次性全历史重下（几千只 × 8,739 天）→ 小时级

## D3 · · 回测遇到坏数据直接拒绝

决定: 回测前先跑完整性检查；区间内有断裂或非正价 → 拒绝出数，而不是"跑出来再说"。

理由: 实测 —— 昨天那 10 组回测里 4 组数据是坏的
（茅台首行 −4.6572 · 招行 5 处断裂），而它们算出 262% / 788%
→ 坏数据会给出"看起来很好"的数字 —— 那比明确报错危险得多
