# 多策略组合 —— 分散化无用，因为它们是同一个信号

> 动机: 单策略都跑不过买入持有 → 但它们的误差可能不相关 → 组合理论上可能有价值
> 判据（两条，都能失败）:
> ① 等权组合 vs 最好的单策略 → 若不超过 → 分散化无用
> ② 等权组合 vs 买入持有 → 若不超过 → 六策略合起来也没有信息
> 样本: 19 只主板 · 2018-01-01 → 2026-06-30 · 含滑点 0.05% · 后复权

---

## 二、 而相关性解释了为什么（这才是关键）

```
 ma20_hold × macd_1d rho = +0.824
 boll_revert × ma20_hold rho = +0.782
 ma20_hold × turtle_donchian rho = +0.743
 boll_revert × bias_revert +0.687
 boll_revert × macd_1d +0.624
 boll_revert × grid_classic +0.619
→ 平均 |rho| = 0.528 → 相关性高
 → 即: 它们说的是同一件事
```

## 三、结论（比单策略的负结论更强）

```
 这六个策略不是"六个独立的弱信号"
 → 而是"一个信号的六种写法"
 → 证据:
 · 平均 rho = 0.528 → 高度相关
 · 组合 +30.53% 低于最好单策略 +69.64% → 合并稀释了
 · 组合 +30.53% 远低于买入持有 +67.66% → 合起来也没有信息
 → → 所以"分散化"在这里不成立
 → 因为分散化要求信号不相关 → 而它们相关

 为什么相关（看它们的定义）:
 · boll_revert（布林带）· ma20_hold（20 日均线）
 · bias_revert（乖离率）· turtle_donchian（唐奇安通道）
 · macd_1d（均线差）· grid_classic（网格）
 → 前五个全部是价格相对均线的位置 → 同一个家族
 → 只有 grid_classic略不同 → 所以它最好
```

## 四、 这个实验补上了什么

```
 之前（第 12 轮）: 单策略平均超额全负 → "找不到"
 本轮: 问"合起来行不行" → 答案: 也不行
 → 而且给出了机制: 它们高度相关 → 不是独立的证据
 → → 所以"多加几个策略"这条路也堵死了
 → 除非新策略来自另一个家族（比如基本面 · 资金流）
```

## 五、下一步（换家族，不是换参数）

```
 这六个都在技术指标家族（价格 vs 均线）
 → 要真正独立的信号必须换数据来源:
 · 基本面（财报 库里有）· 资金流（需新数据源）
 · 龙虎榜 / 大宗交易（需新数据源）· 行业轮动（需行业指数 库里有）
 → 判据下次也可以用同一个: 新信号与这六个的 rho 应当低
 → 若rho 也高 → 那它不是新家族
```
