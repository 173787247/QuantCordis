# 因子研究（可复现）· 以及一次结论翻转

> 为什么有本文档: 因子研究的结论要能复核（判据可复现）
> → 而今天的研究结论都来自 /tmp 的一次性脚本 → /tmp 会丢 → 那不叫可复现
> 本轮: 固化成 `tools/factor_study.py`

---

## 一、 工具

```bash
python tools/factor_study.py ic # 横截面 IC 检验（Spearman · 不重叠季度）
python tools/factor_study.py layer # 分层回测（Top20% vs 全市场等权 · 扣成本 0.16%）
python tools/factor_study.py neutral # 市值中性化（5 组内再排 E/P）
```

判据（每条都能失败）:
```
ic : |t| > 2 且 IC 均值 > 0.02
layer : Top20%（扣成本）> 全市场等权
neutral : 中性化后超额保留 > 50% → 不是小市值代理
```

防未来函数: 财报表只有 `report_date` 没有公告日 → 用法定披露截止日
（一季报 4/30 · 半年报 8/31 · 三季报 10/31 · 年报次年 4/30）
eps 是累计值 → 按报告期年化 （Q1×4 · H1×2 · Q3×4/3 · 年报×1）


```
 今天上午的 zz_ic.py（12 期）:
 roe +0.0687（t=+1.75）· low_debt +0.0647（t=+2.55）
 ep +0.0861（t=+2.13）· growth +0.0736（t=+4.21）
 → "四个里三个通过 t 检验"

 固化版（19 期）:
 roe −0.0179（t=−0.51）· low_debt −0.0142（t=−0.79）
 ep +0.0406（t=+1.07）· growth +0.0065（t=+0.21）
 → 一个都没通过

 根因:
 · zz_ic.py 查价格用 `WHERE trade_date = avail_date` 精确匹配
 · → 而法定截止日（如 6/30 · 9/30 · 12/31）往往不是交易日
 · → 返回空 → 静默跳过那一期
 · → 26 期里只配了 12 期 → 而且跳过不是随机的
 （取决于截止日是不是周末/假期）→ 选择偏差
 · 固化版用 `px_on` → 取当天或之前最近交易日 → 配了 19 期
```

## 三、结论必须改

```
 上午写的: 「四个因子 IC 都有预测力 · growth 最强 t=+4.21」
 现在: 四个因子都不通过 t 检验
 → 即: 在 IC 这一层，就没有统计显著的因子
 → 而那与ep 分层回测跑赢并不矛盾:
 · IC 衡量全截面单调性
 · 分层只看Top 20% → 两端信息用不上
 · → 而ep 的分层超额在样本外也确实衰减到负（另一次独立验证）
```

## 四、 这一轮真正的价值

```
 "可复现"不是文档要求 → 它是发现错误的手段
 → 固化立刻暴露了两次运行结果不一致
 → 而如果我只留 /tmp 脚本 → 永远发现不了
 → 这也是今天第 9 个假通过 —— 而它是最严重的一个
 → 因为它影响了一个核心结论（"因子有预测力"）
```

## 五、 附带修好的两个缺陷

```
 ① 工具自己读 .env（原版连上但被拒 → 没密码）

 ② 工具在 WSL 侧可直接跑:

```
